My Final Project Proposal

My website will be about a small creature that gets lost in a huge forest. Over time the creature learns how to survive and live there. As the user explores the website, they will discover parts of the forest with the creature.

Website Description

The website may include story pages, forest environments, hidden creatures, and exploration sections.

Fonts and Colors

I want to use dark shades of green, yellow, and brown to match the forest atmosphere. For fonts, I'm thinking of using typewritter or handwritten styles.

p5.js Element

jQuery Element
